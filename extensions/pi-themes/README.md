# pi-themes

Dark-background themes for Pi. Package declares `pi.themes: ["./themes"]`, no code, root references `extensions/pi-themes/themes`.

- `flatland.json` (`flatland`, muted pastel)
- `noir.json` (`noir`, muted pastel, renamed from mono-black)
- `abyss.json` (`abyss`, deep navy blue, aqua success, rose error)
- `ember.json` (`ember`, warm charcoal brown, amber accent, flame error)
- `moss.json` (`moss`, forest green, leaf success, brick error)
- `dusk.json` (`dusk`, plum purple, mint success, magenta error)
- `gilt.json` (`gilt`, dark gold, lime success, red-orange error)
- `crimson.json` (`crimson`, dark red, vivid red error)
- `azure.json` (`azure`, bright cobalt blue, teal success)
- `magma.json` (`magma`, vivid orange, lime success, flame error)
- `lagoon.json` (`lagoon`, turquoise, sea-green success, salmon error)
- `orchid.json` (`orchid`, vivid pink, mint success, magenta error)
